# mini-elements-navigator

travelers guide for zero gravity botany: a one-page reference for mini-elements, the alt firmware for the mutable instruments rings by lylepmills. the five modes, elements' bow, blow and strike exciters, frequency lock, the options menu, hold on strum, the chord tables, outputs by mode, install and calibration, with diagrams.

live page: https://mellotom.github.io/mini-elements-navigator/
part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

compiled from the alt firmware readme (https://github.com/lylepmills/eurorack/tree/master/alt_firmwares) and checked against its source. not affiliated with mutable instruments or lylepmills.
